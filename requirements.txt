# fastapi-cli, which requires typer>=0.12.3; spacy==3.7.4 pins
# typer<0.10.0 directly — those two floors never overlap, so installing
# both together is ResolutionImpossible, not a build/platform issue.
# spacy==3.7.5 relaxed its pin to typer<1.0.0 (and its weasel dependency
# to a version with the same relaxed range), which overlaps cleanly with
# fastapi-cli's floor. Verified via `pip install --dry-run --only-binary
# :all: --python-version {3.11,3.12} --platform manylinux2014_x86_64` —
# resolves clean on both, installing typer==0.24.2.
#
# If you still hit resolution/build issues in a different environment,
# use requirements-deploy.txt instead — the app runs fully functional on
# the regex fallback without Presidio/spaCy at all (see SECURITY.md "PII
# Detection Coverage"). CI runs both: requirements-deploy.txt is the
# blocking gate, this full file gets an advisory (non-blocking) job.
#

#   pip install -r requirements.txt
#   python -m spacy download en_core_web_lg   # Presidio NLP model
